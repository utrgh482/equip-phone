# 장비 수리 대장 — 핸드폰 (equip-phone)

여주시농업기술센터 **장비 수리 대장**의 핸드폰용 화면과 안드로이드 껍데기입니다.

- `docs/` — 핸드폰에서 여는 페이지 (GitHub Pages). **자료는 들어 있지 않습니다.**
- `c/` — 사람마다 잠긴 연결 파일. 그 사람의 비밀번호 없이는 열 수 없습니다.
- `app/` — 페이지를 여는 안드로이드 앱(껍데기). GitHub Actions 가 apk 를 만들어 Releases 에 올립니다.

장비·수리 기록은 사무실 PC 의 서버와, 각자의 비밀번호로 잠긴 우편함(비공개 저장소)에만 있습니다.
이 저장소의 파일은 사무실 서버가 자동으로 올립니다 — 손으로 고치지 마세요.
